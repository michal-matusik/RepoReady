## Student-created diagram required

The assignment requires the student to draw the System Diagram using draw.io, Lucidchart, or a comparable diagramming tool.
AI-generated diagrams earn a zero for that section.
No diagram, generated source, or substitute artifact is included in this setup.

Provide the exported image as `System Diagram.png` or `System Diagram.jpg` and the editable source as `System Diagram.drawio` or the corresponding native format.
Check the diagram against the assignment's requirements for the updated MVP, labeled connections, and a clear starting point.
Upload the student's actual files without regenerating or misrepresenting their authorship.
Embed the student's image in the assignment/design document as requested by the course.

## Final commit check

Use one atomic follow-up commit on the default branch to add the real image and editable source and update this checklist and the README.
Keep `Eisenhower Matrix.md` at the root in that same commit snapshot.
An existing tracked file remains included in later commit snapshots even if it does not need another edit.
If the matrix needs revision, include its final revision in that follow-up commit.
Do not rewrite published history solely to combine setup work with the later diagram upload.

Before submitting, open the public repository while signed out and confirm that the latest default-branch tree contains both clearly named deliverables at its root.
Open the image to confirm that it displays correctly and check that the editable source opens in the student's diagramming tool.
Do not mark the submission complete until these checks pass.
